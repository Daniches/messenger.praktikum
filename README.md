# Мессенджер
SPA мессенджер, разработанный в рамках курса [Мидл фронтенд-разработчик](https://practicum.yandex.ru/middle-frontend) от Яндекс.Практикум

## Требования
* NodeJS v22.12+

## Запуск проекта
Склонируйте репозиторий

Установите зависимости -  `npm install`

Для локального запуска дев окружения - `npm run dev`

Для сборки проекта - `npm run build`
